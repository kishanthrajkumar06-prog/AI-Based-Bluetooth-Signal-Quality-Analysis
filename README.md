# AI-Based Bluetooth Signal Quality Analysis (Capstone Project 14)

A complete, beginner-friendly Python project that classifies Bluetooth link quality as **good**, **moderate**, or **poor** using RSSI, packet loss, latency, distance, interference, obstacles, and connection status.

## Important data note
The included CSV is a **synthetic demonstration dataset generated by `generate_dataset.py`**. It is not measured from a real Bluetooth device. For a real-world capstone evaluation, replace it with collected measurements while keeping the same column names, or adapt the preprocessing code.

## Features
- Dataset generation and preprocessing
- Random Forest classification using scikit-learn
- Accuracy, macro F1-score, classification report, and confusion matrix
- Saved model pipeline
- Streamlit dashboard for interactive predictions
- Graphs for signal conditions vs. quality
- Project report and presentation

## Quick start
Use Python 3.10 or newer.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python generate_dataset.py
python train_model.py
streamlit run app.py
```

The Streamlit page will open in your browser. Enter link conditions and select **Predict quality**.

## Project files
- `app.py` — interactive Streamlit application
- `generate_dataset.py` — creates a reproducible synthetic sample dataset
- `train_model.py` — trains and evaluates the model, saves metrics and plots
- `data/bluetooth_signal_dataset.csv` — generated demo dataset
- `models/` — trained model after running training
- `outputs/` — evaluation results and plots after running training
- `report.md` — project report draft
- `presentation.pptx` — project presentation
- `requirements.txt` — Python dependencies

## Dataset columns
| Column | Meaning |
|---|---|
| `distance_m` | Approximate separation between Bluetooth devices in metres |
| `rssi_dbm` | Received Signal Strength Indicator in dBm (more negative usually means weaker signal) |
| `packet_loss_pct` | Percentage of transmitted packets that were lost |
| `latency_ms` | Approximate round-trip delay in milliseconds |
| `interference` | Categorical demo level: low, medium, high |
| `obstacles` | Count of obstacles in the demo scenario |
| `connection_status` | connected or unstable |
| `quality` | Target class: good, moderate, poor |

## Real measurements
Record multiple trials at different distances and interference conditions. Log RSSI from a Bluetooth utility, measure packet loss and latency using a repeatable test, and document the device, OS, Bluetooth version, and environment. Do not claim synthetic values are real measurements. Make sure labels are defined consistently. If using actual data, review the quality thresholds in `generate_dataset.py` / data-collection protocol and retrain.

## Limitations
- Synthetic data may produce optimistic evaluation scores and cannot establish real-world performance.
- RSSI and link quality vary by chipset, antenna orientation, walls, Wi-Fi traffic, and Bluetooth version.
- This is an educational prototype, not a safety-critical network monitor.
